```
mask
------------
N = 9
0 - 1| 0 - 4 
=> unite mask : 0001 0010 = 12[h] + a reg inversion

Скласти програму для визначення кількості однобайтних 
двійкових чисел x, які мають задані значення (0) і (0)
двійкових розрядів із номерами 4 і 1 з їхнього масиву,
що містить в адресах пам'яті 8040 - 804A відповідно варіанту.
```

```
------------
setup block
------------
06 00    : mvi b 00 ( b reg contain x)
21 40 80 : lxi 8040 ( hl=[m] <-- 8040 )
0E 0B    : mvi c 0b ( c reg - counter ) ( num of cycles 0b=11 )
------------
m1
------------
bit 1 is present - result 0000 0010 ≠ 0
bit 4 is present - result 0001 0000 ≠ 0
both bits are present - result 0001 0010 ≠ 0

7E : MOV A,M            
E6 : ANI 12h
CA 15 80 : JZ skip
04 : INR B
------------
skip
------------
23       : inx h ( hl + 1) 8040 / 8041 ... 804A
0D       : dcr c ( c - 1) 11 - 1 = 10 / 9 ... 0
C2 XX XX : jnz m1 ( = 1 => jump | = 0 ... hlt)
76       : hlt
```
