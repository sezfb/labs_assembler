### Добуток двійкових кодів чисел a & B
--------------------------------------------------------------------------------------------------------------
```
а = 1011 0111[B] - відповідає додатковому коду від'ємного числа
=> |a| :
інверсія - 1011 0111 + 1
        => 0100 1001[B] = 1 + 8 + 64 = 73[D]

|a| = Bx7[H]

b = 0000 1100[B] = 12[D] - відповідає прямому коду додатного числа
|b| = 0xC[H]
```

 ```

```
Урахування знаків співмножників у [a * b] додатковому коді :
